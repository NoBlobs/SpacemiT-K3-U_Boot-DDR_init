# Appendix: LPDDR5 1D PMU Message Block Fields

## Scope and conventions

This appendix records the complete 293-field CSR layout supplied by the reference CSV. The structure spans **320 bytes**, offsets `0x000` through `0x13f`. The host-visible message block starts at CSR `0x58000`; the PMU internal copy used by the streaming filter starts at DMEM `0x80000000`.

Offsets are byte offsets within the structure. CSR addresses are the values recorded in the source. Direction labels are normalized case-insensitively: **200 In**, **74 Out**, and **19 N/A**. Multi-byte fields follow the target little-endian layout. The catalog preserves offsets, addresses, directions, types, and names, but deliberately does not reproduce upstream descriptive comments.

For address derivation, byte offset `o` maps to CSR `0x58000 + floor(o/2)`; an odd byte offset shares a CSR with the preceding even byte. For the internal copy, the corresponding byte address is `0x80000000 + o`.

Important control fields include `MsgMisc` at `0x001` and `HdtCtrl` at `0x012` (CSR `0x58009`, internal byte `0x80000012`). The documented `HdtCtrl` thresholds are `0x05` (eye delays), `0x0a` (rank), `0xc8` (stage), `0xc9` (assert), and `0xff` (completion only).
